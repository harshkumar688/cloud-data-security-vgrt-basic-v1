INTER-MODULE ARCHITECTURE

How Governance Events Feed the Risk Engine

The Risk Assessment engine is strictly coupled to the Governance subsystem. When a governance policy is breached (such as an unauthorized IDOR file request or repeated credential failures), the event propagates synchronously into the audit ledger and adjusts real-time risk scores.

1 Policy Interception

Governance filters intercept file requests. If tenant principal ≠ file owner, access is blocked immediately.

2 Audit Propagation

A DENIED or FAILURE event is written to AuditEventRepository with actor username and resource ID.

3 Telemetry Aggregation

RiskService executes deterministic counter queries across recent failure/denial events.

4 Score & Alert Surface

Mathematical formula updates risk index, triggering warning badges on Security Dashboard and Audit Ledger.
