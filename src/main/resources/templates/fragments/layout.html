V-GRT Security & Cryptography

ENCRYPTION ENGINE

Hybrid Envelope Cryptography

Each upload generates an ephemeral 256-bit symmetric key encrypted via RSA-OAEP (SHA-256).

Symmetric Cipher: AES-256-GCM (128-bit Tag)
Asymmetric Key Wrapping: RSA-OAEP-2048 / MGF1-SHA256
Digest Integrity: SHA-256 Verified on Download
Password KDF: BCrypt (Cost Factor 12)

Plaintext bytes are never persisted in the database; only encrypted ciphertext, wrapped keys, and initialization vectors are committed to disk.
