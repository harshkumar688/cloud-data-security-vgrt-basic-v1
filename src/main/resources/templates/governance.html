Strict Row-Level Ownership

Every SQL query for file retrieval, verification, or deletion enforces WHERE owner_username = :current_user. Direct ID guessing (IDOR) fails immediately and logs a security denial event.

Ephemeral Data Key Isolation

A unique 256-bit AES key is generated in memory for every single uploaded file, wrapped with the RSA-2048 master key, and discarded immediately after ciphertext flush.

Storage Disassociation Guard

Objects on disk are named via random UUID storage keys (e.g. c4f1a8e2.bin). No plaintext file paths, filenames, or user metadata are ever persisted on physical storage volumes.
