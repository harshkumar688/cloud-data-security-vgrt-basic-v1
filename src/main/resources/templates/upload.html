SYMMETRIC CIPHER

AES-256-GCM (Authenticated)

Active

Every uploaded object generates a fresh 256-bit symmetric data key via SecureRandom. The file payload is converted into ciphertext with a 128-bit authentication tag, guaranteeing confidentiality and preventing unauthorized byte manipulation.

KEY WRAPPING

RSA-OAEP-2048 Enclave

Asymmetric

The symmetric AES key is never stored in plaintext. It is encapsulated using RSA-OAEP with SHA-256 and MGF1 masking. Only the verified tenant holding private key authorization can trigger decryption during download streams.

INTEGRITY DIGEST

SHA-256 Integrity Check

Deterministic

Before encryption, a 256-bit cryptographic hash of the original byte stream is calculated. This checksum is validated upon every download; if a single bit has been corrupted, the delivery pipeline terminates instantly.
